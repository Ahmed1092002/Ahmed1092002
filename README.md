### ✈️ Travel Hub — Hotel Booking Platform

A full-stack hotel discovery and booking platform supporting customers, sellers and administrators.

- Customer reviews with seller responses

- Seller dashboards for hotels, rooms, pricing and analytics
- Admin statistics, user management and audit logs
- Interactive maps and responsive layouts

**Frontend:** Next.js, React, TypeScript, Zustand, Tailwind CSS, Radix UI, React Hook Form, Zod and Leaflet  
**Backend:** Java, Spring Boot and REST APIs
